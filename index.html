— Project 02
PixelPhantom
v2.0.0 · 90/90 tests passing · MIT License

A desktop application for detecting and removing duplicate image, video, and audio files using pixel-direct comparison — no hashing at any stage. Files are only flagged as duplicates if their actual decoded pixel data is identical, making it immune to re-encoding artifacts that fool MD5/SHA-based tools.

Built with a three-phase scan pipeline: a size gate eliminates ~90% of files instantly, a dimension gate handles another layer, only remaining files undergo full pixel comparison via Pillow's tobytes(). All scanning runs in background daemon threads. Files go to a recycle bin — never permanently deleted without confirmation.
