PixelPhantom
Duplicate file detector · v2.0.0 · 90/90 tests passing · MIT License

Python tool for finding duplicate images, video, and audio files using pixel-direct and byte-level comparison — no hashing. Three-phase pipeline: size gate → dimension gate → pixel compare. Scanning runs in background threads. Files go to a recycle bin by default.
